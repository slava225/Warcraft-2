# Тёплый поиск — визуальная новелла

Личная визуальная новелла о бережном знакомстве без фото и видео, созданная для мобильных экранов.

🌐 **GitHub Pages:** https://slava225.github.io/Warcraft-2/

## Возможности

- 💬 **Диалоговая система** — выбор реплик влияет на настроение, искренность и взаимность.
- 📝 **Заметки и подсказки** — история подсказывает, что важно запомнить.
- 📱 **Мобильный фокус** — крупные тач‑зоны и адаптивный интерфейс.
- 💾 **Сохранение прогресса** — продолжаешь историю с того же места.

## Локальный запуск

1. Запусти локальный сервер:
```bash
python3 -m http.server 8000
```

2. Открой в браузере:
```
http://localhost:8000
```

## Структура

- `index.html` — разметка и стили новеллы.
- `js/game.js` — логика сцен, выборов и сохранения.

## GitHub Pages

Этот репозиторий использует GitHub Actions для публикации страницы. Убедись, что в **Settings → Pages** выбран источник **GitHub Actions**. Публикация запускается при пуше в ветку `codex/create-visual-novel-dating-game-7rx40p`.

Если на странице всё ещё отображается старая версия, проверь:
- в **Pages** выбран источник **GitHub Actions**;
- публикация идёт из ветки `codex/create-visual-novel-dating-game-7rx40p` с текущими файлами.
